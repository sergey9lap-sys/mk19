# DESIGN_RULES.md — Website Design Rules for Agents

These are mandatory design rules for creating websites for Sergey Lapin.

## Main Design Goal

Create websites that feel:

- clean;
- modern;
- readable;
- visually collected;
- adaptive;
- alive through motion;
- not template-like.

The agent must improve visual presentation without changing the provided marketing structure.

## Typography

Typography is one of the main reasons a website feels expensive or cheap.

Rules:

- do not create absurdly huge headings;
- hero headings must be expressive but controlled;
- headings should usually take 2–4 lines on desktop, not the whole viewport height;
- body text must be readable;
- line length must be comfortable;
- heading levels must be consistent;
- body text sizes must be consistent;
- avoid random font changes;
- use no more than 1–2 font families unless the project intentionally requires more.

Good typography guides attention:

heading → subheading → key accent → action.

## Line Breaks and Orphan Words

Manually manage line breaks in important text areas:

- Hero headings;
- section headings;
- subheadings;
- cards;
- CTA blocks.

Do not leave lonely words at the end of a line:

- prepositions;
- conjunctions;
- particles;
- dashes;
- slashes;
- short service words.

Bad:

Создаём сайты для  
экспертов и продуктов

Good:

Создаём сайты  
для экспертов и продуктов

Bad:

Опыт, который работает в  
запусках

Good:

Опыт, который работает  
в запусках

## Spacing

Do not create excessive empty space between sections.

Sections should breathe, but the page must not feel empty or artificially stretched.

Use the spacing scale:

4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96

Related elements must be closer to each other.

Examples:

- heading and subheading: closer;
- subheading and next content group: farther;
- items inside one card: closer;
- different cards: farther.

## Optical Alignment

Do not rely only on mathematical alignment.

The human eye sees real objects, not invisible containers:

- text;
- icons;
- photos;
- buttons;
- card edges.

If mathematically equal spacing looks visually wrong, adjust visually.

Example:

- 32px top and 32px bottom may feel uneven;
- 28px top and 36px bottom may look better.

If math says one thing and the eye says another, fix the visual result.

## Visual Hierarchy

Every section must have a clear attention path.

For each section, define:

1. First attention object.
2. Second attention object.
3. Third attention object.
4. Target user action.

Rules:

- the main element must be the most noticeable;
- secondary elements must not compete with the main one;
- decorative elements must not steal attention;
- CTA must be visible;
- if everything is equally important, nothing is important.

Before finishing a section, check whether the main point is clear within 2–3 seconds.

## First Screen / Hero

The first screen must quickly answer:

1. Who is this?
2. What is offered?
3. Who is it for?
4. What should the user do next?

Hero should include:

- clear heading;
- short subheading;
- visible CTA;
- visual accent;
- no visual noise.

Do not make Hero explain the whole project. Hero must create clarity, interest, and action.

## Composition

Each section must be designed as a composition, not just stacked content.

Before designing a section, identify:

- main element;
- secondary element;
- visual accent;
- next attention direction.

Rules:

- do not make all elements equally important;
- do not overload the section;
- do not place cards and text randomly;
- use grid, contrast, size, and spacing to guide attention.

Even a simple section with heading, text, and three cards must feel composed.

## Contrast

Contrast is not only color.

Use contrast through:

- size;
- font weight;
- color;
- background;
- shape;
- movement;
- spacing;
- placement.

Rules:

- light background → dark text;
- dark background → light text;
- light background → dark/contrast cards;
- dark background → light/contrast cards;
- text inside cards must contrast with the card background;
- CTA must contrast with its section.

Never create:

- light text on light background;
- dark text on dark background;
- white cards on white background without visible separation;
- multiple nearly identical background sections in a row.

If a section feels flat, it probably lacks contrast.

## Background Rhythm

Avoid 3–4 same-tone sections in a row.

If the palette uses light and dark sections, alternate visual mood where appropriate.

Example:

- Hero: light;
- next section: dark;
- next section: light;
- next section: dark.

This is not a strict rule, but the page must visually move.

## Page Rhythm

The page must not feel like repeated blocks.

Bad rhythm:

Hero → cards → cards → cards → text → cards

Better rhythm:

Hero → meaning section → cards → visual section → CTA → cards → final accent

Rules:

- alternate dense and light sections;
- alternate text-heavy and visual sections;
- avoid 3–4 same-structure sections in a row;
- use CTA and visual transitions to change rhythm.

A good website feels like a route, not a spreadsheet of sections.

## Attention Stops

Users do not read evenly. They scroll, stop, read an important element, then continue.

Create attention stops:

- large phrase;
- strong card;
- big number;
- quote;
- visual accent;
- photo;
- CTA block.

Without attention stops, the page feels like a long scroll sheet.

## Visual Bridges Between Sections

Sections should not feel abruptly cut.

Create bridges using:

- gradient;
- repeated decorative element;
- background continuation;
- line;
- light;
- particle;
- form;
- mini-CTA;
- visual hint toward the next section.

The website must feel like one journey, not separate slides.

## Visual Noise

Avoid adding effects without purpose.

Be careful with:

- glows;
- shadows;
- gradients;
- borders;
- patterns;
- icons;
- animations;
- decorative elements.

Rule: if removing an element does not hurt meaning, atmosphere, or action, the element may be unnecessary.

## One Strong Visual Concept

Each website should have one main visual language.

Bad:

3D + neon + glass + sakura + space + parallax + noise + gradients.

Good:

one main visual concept + supporting details.

Example:

- sakura as main concept;
- dark cinematic background;
- soft particles;
- subtle animation.

## Premium Through Simplicity

An expensive-looking website often removes unnecessary elements.

Before finishing, ask:

- can an icon be removed?
- can a text block be shorter?
- can an effect be removed?
- can a card be simpler?
- can the section feel cleaner?

If an element does not strengthen meaning, atmosphere, or action, remove or simplify it.

## Images

Images must strengthen the website.

Before using an image, check:

- does it strengthen the section meaning?
- does it match the style?
- does it compete with the text?
- does it hurt readability?
- does it look random?

Good image usage:

- part of the composition;
- aligned with mood;
- optimized by weight;
- integrated with background when needed.

Bad image usage:

- image added just to fill space;
- rough rectangular Hero image without concept;
- image overlapping text;
- random stock feeling.

## Mobile Composition

Mobile is not compressed desktop.

Check separately:

- element order;
- heading size;
- readability;
- spacing;
- buttons;
- images;
- animation logic.

On mobile, prefer:

- vertical stacks;
- one card per row;
- bottom-sheet patterns;
- simple reveal animation;
- sticky CTA when useful;
- shorter blocks;
- less parallax;
- less horizontal movement.

If desktop is impressive but mobile is only “okay”, mobile is unfinished.

## Clickable Areas

Beautiful is not enough. The website must be easy to use.

Rules:

- buttons must be easy to tap;
- links must not be too small;
- important mobile elements must be thumb-friendly;
- if a card looks clickable, make the whole card clickable when possible.

## Visual System

The website must feel like one system.

Define and follow:

- palette;
- font system;
- heading sizes;
- text sizes;
- border radius;
- shadows;
- spacing;
- icon style;
- card style;
- button style;
- animation style.

Do not:

- mix card styles randomly;
- use random border-radius values;
- change button style from section to section;
- use random colors;
- combine too many effects;
- make every section feel like a different website.

If the logo is removed, all sections should still feel like they belong to the same project.

## Punctuation Consistency

Punctuation must be consistent.

Do not:

- use a period in one card and no period in the next;
- use a period in one heading and not in another;
- mix dash, quote, and list styles randomly.

Rules:

- if cards end without periods, all similar cards end without periods;
- if list items use periods, all similar list items use periods;
- use one dash style consistently.
