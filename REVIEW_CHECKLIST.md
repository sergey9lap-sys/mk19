# REVIEW_CHECKLIST.md — Final Website Review for Agents

Use this checklist before marking any website task as complete.

## 1. Specification

- [ ] The website follows the user’s technical specification.
- [ ] The block order was not changed without instruction.
- [ ] Provided copy was not rewritten or shortened in meaning.
- [ ] No unnecessary sections were added.
- [ ] No required sections were removed.

## 2. First Screen

- [ ] Hero is understandable within 3 seconds.
- [ ] Hero answers: who, what, for whom, what next.
- [ ] Hero heading is expressive but not absurdly huge.
- [ ] Hero CTA is visible.
- [ ] Hero image, if present, is part of the composition.

## 3. Typography

- [ ] Heading scale is consistent.
- [ ] Body text size is readable.
- [ ] Line length is comfortable.
- [ ] Important headings do not have orphan prepositions or lonely short words.
- [ ] No random font changes.
- [ ] Punctuation style is consistent.

## 4. Spacing and Composition

- [ ] There is not too much empty space between sections.
- [ ] Related elements are close to each other.
- [ ] Sections feel composed, not randomly stacked.
- [ ] Visual hierarchy is clear.
- [ ] Each section has a main attention object.

## 5. Contrast and Readability

- [ ] Text is readable on every background.
- [ ] No light text on light background.
- [ ] No dark text on dark background.
- [ ] Cards are separated from their section background.
- [ ] CTA buttons contrast with their sections.

## 6. Page Rhythm

- [ ] There are no 3–4 same-tone sections in a row.
- [ ] There are no 3–4 same-structure sections in a row.
- [ ] Page has attention stops.
- [ ] Sections have visual bridges where useful.
- [ ] Page feels like a route, not a set of disconnected blocks.

## 7. CTA

- [ ] Hero CTA is visible.
- [ ] CTA appears approximately every 2 sections when appropriate.
- [ ] CTA text is clear.
- [ ] CTA buttons are not too small.
- [ ] CTA buttons are easy to tap on mobile.

## 8. Mobile

- [ ] Mobile layout is checked separately.
- [ ] No horizontal scroll.
- [ ] No text-image overlap.
- [ ] Cards are comfortable in vertical flow.
- [ ] Buttons are thumb-friendly.
- [ ] Mobile animation is simplified if needed.
- [ ] Important CTA is not hidden.

## 9. Animation

- [ ] Site is not fully static if motion libraries are used.
- [ ] Animations are subtle and useful.
- [ ] Animations follow one visual language.
- [ ] No random flip/zoom/rotate/bounce mix.
- [ ] Motion does not break mobile UX.
- [ ] Motion does not make the site heavy.

## 10. Images and Performance

- [ ] PNG is used only when transparency is required.
- [ ] Backgrounds are WebP/JPG/AVIF when possible.
- [ ] Images are optimized.
- [ ] No unnecessary heavy assets.
- [ ] No too many heavy effects at once.

## 11. Interface States

- [ ] Buttons have hover/focus/active states.
- [ ] Forms have focus/error/success states.
- [ ] Disabled/loading states are clear where relevant.
- [ ] Links and cards have appropriate interactive feedback.

## 12. Visual System

- [ ] Color palette is consistent.
- [ ] Border radius is consistent.
- [ ] Shadows are consistent.
- [ ] Button style is consistent.
- [ ] Card style is consistent.
- [ ] Icon style is consistent.
- [ ] Animation style is consistent.
- [ ] Site does not look like default shadcn blocks.

## 13. Final Quality Test

- [ ] Website feels clean and modern.
- [ ] Website is not visually noisy.
- [ ] One strong visual concept is clear.
- [ ] Nothing important is hidden too deep.
- [ ] The site feels like one complete product.
